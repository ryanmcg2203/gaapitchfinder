Open GAA Pitch Dataset

GAA Pitch Finder publishes an open GAA club and pitch locations dataset maintained by Ryan McGuinness. It contains 1,989 GAA pitch records worldwide, including club names, pitch names, coordinates, directions, elevation, rainfall data, and regional groupings.

Dataset generated from the canonical data revision dated 6 August 2026.

View current dataset health, provenance, and known limitations.

The dataset powers the public GAA Pitch Finder map, club pages, county pages, and directions pages. It is available for research, education, community projects, and other useful GAA mapping work.

Compatibility

The download URLs remain stable and always point to the latest published data. The schema uses semantic versioning: optional additions and new controlled values are backward-compatible, while renamed or removed fields, type changes, tighter nullability, a new coordinate reference system, or a different geometry type require a new major schema version.

Consumers should ignore unknown fields and should not assume controlled vocabularies are permanently closed. The exact machine-readable policy is included in the JSON schema.
