From a GAA Map to an R Package

18 October 2026 · 3 min read

When I started GAA Pitch Finder, the goal was fairly simple: create a useful map of GAA pitches in Ireland and around the world.

Over time, the project became more than a map. It developed into an open dataset containing nearly 2,000 pitch locations, with information about clubs, counties, coordinates, elevation, rainfall, directions, and more.

Recently, I was delighted to discover that Vincent Tennanty had used the dataset to create gaapitchfinder, an R package for exploring and analysing GAA pitch locations.

What the package can do

The package makes it possible to:

  • Search for pitches by name, club, or county
  • Find the nearest pitches to a location
  • Find pitches within a specified radius
  • Generate county-level summaries
  • Visualise pitch locations using ggplot2
  • Work entirely offline after installation

Why this matters

This is exactly the kind of use I hoped the dataset might support. The original project was built as a website, but publishing the underlying data openly means that other people can use it in ways I had not anticipated.

The R package could be useful for analysts, researchers, journalists, GIS practitioners, county boards, and anyone interested in the geography of Gaelic games. It also shows the value of publishing data in a reusable format rather than keeping it locked inside a single website.

Open data has a life of its own

A big thank you to Vincent for building the package and for crediting the original GAA Pitch Finder dataset. It is hugely encouraging to see the project being reused and extended by someone else.

The package is currently available on GitHub and has been submitted to CRAN:

View the gaapitchfinder R package on GitHub

This is a great reminder that open data can develop a life of its own. A project may begin as a map, but with the right data and documentation, it can become a foundation for analysis, research, and entirely new tools.

I would be delighted to see what people build with it next.
